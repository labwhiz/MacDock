## 二、竞品劣势清单（可做视频文案）

### 1. RocketDock（免费但停更）
- 官方版本停留在 **v1.3.5**，架构老、多年无实质更新
- 官网 FAQ 自认：Win11 需要「compatibility fix（兼容性修复）」才能运行
- 贴吧用户反馈：Win10 下运行一段时间后失效
- 动画生硬、界面老旧，毛玻璃/半透明在新系统上效果差
- 32 位老程序，高分屏/DPI 缩放发虚

### 2. Winstep Nexus（免费+付费 Pro）
- 免费版功能受限，官网主推「Nexus Ultimate 专业增强版」，需要购买
- 界面风格老气，动画跟手度一般
- 卸载残留、设置项繁琐，学习成本高

### 3. ObjectDock（Stardock，纯收费）
- 需要付费购买，没有完整免费版
- 多年无大版本更新，Win11 兼容性时好时坏
- 功能堆叠、上手门槛高

### 4. FalconX（不是真 Dock）
- 只是把任务栏图标居中 + 透明，**不是真正的 Dock 栏**
- 无图标放大动画、无毛玻璃 Dock、无文件夹面板等核心功能
- 免费版在 GitHub，商店版需付费支持

### 5. MyDockFinder（功能全但争议多）
- GitHub Issue #343「既然收费了就想好好说说」：收费模式引发用户不满
- 网上有「mydockfinder收费吗」等大量疑问帖
- 社区反馈：安装捆绑、内存占用偏高、偶发卡顿

## 三、宣传视频对比角度
1. **免费无广告** vs 收费/弹窗/捆绑
2. **轻量丝滑** vs 老旧卡顿
3. **持续更新、原生适配 Win11** vs 停更/需要兼容补丁
4. **真正的 Dock 体验**（放大动画/毛玻璃/文件夹面板/拖放）vs 半成品工具
